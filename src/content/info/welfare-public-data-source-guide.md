“작년까지는 됐다는데 올해도 되나요?” 복지사업을 검색하면 가장 막히는 지점입니다. 블로그 글에는 기준연도가 없고, 정부 보도자료는 이미 바뀐 내용일 수 있습니다. 이럴 때 기준연도와 최종수정일이 함께 붙어 있는 공공데이터를 먼저 보면 판단이 빨라집니다.

복지 신청 전에는 블로그 요약보다 공식 데이터의 기준연도, 최종수정일, 소관부처, 문의처를 먼저 확인하는 편이 안전합니다. 공공데이터포털에는 복지로 기반의 중앙부처 복지서비스 정보가 파일데이터와 오픈API 형태로 공개되어 있습니다.

## 신청 전 체크

| 항목 | 확인할 내용 | 준비 자료 |
|---|---|---|
| 사업명 | 공고문과 데이터의 서비스명이 같은지 | 사업 공고문 |
| 기준연도 | 올해 기준인지, 지난해 자료인지 | 데이터의 기준연도 항목 |
| 소관부처 | 중앙부처 사업인지 지자체 사업인지 | 소관부처·소관조직 항목 |
| 지원대상 | 소득·재산·연령·가구 조건 | 서비스URL의 상세 안내 |
| 접수기간 | 상시인지 기간제인지, 예산 소진 여부 | 복지로 또는 담당 기관 공지 |
| 문의처 | 실제 연결되는 번호인지 | 대표문의 항목 |

| 확인 항목 | 왜 봐야 할까 |
|---|---|
| 서비스명·서비스URL | 복지로 상세 페이지에서 최신 신청 안내로 이동할 수 있습니다. |
| 서비스요약 | 내가 찾는 급여, 감면, 바우처, 상담 서비스인지 빠르게 구분합니다. |
| 대표문의 | 온라인 신청 전에 전화로 대상 여부를 확인할 수 있습니다. |
| 소관부처·소관조직 | 제도 변경 공고를 찾을 때 기준 기관을 좁힐 수 있습니다. |
| 기준연도·최종수정일 | 오래된 안내인지, 올해 기준으로 봐도 되는지 점검합니다. |

## 어디서 확인할까

| 자료 | 활용 방법 |
|---|---|
| [한국사회보장정보원_복지서비스정보](https://www.data.go.kr/data/15083323/fileData.do) | 중앙부처 복지사업의 서비스명, URL, 요약, 대표문의, 기준연도, 최종수정일을 한 번에 볼 때 사용합니다. |
| [한국사회보장정보원_중앙부처복지서비스](https://www.data.go.kr/data/15090532/openapi.do) | 서비스 목록과 상세 정보를 API로 확인해야 할 때 사용합니다. |
| [복지로](https://www.bokjiro.go.kr/) | 실제 신청 가능 여부, 접수 화면, 최신 공지 확인에 사용합니다. |

복지체크에서 월소득, 주거비, 부채, 금융재산을 먼저 계산한 뒤 위 자료의 선정기준과 비교하면 내가 상담 전에 준비해야 할 숫자를 빠르게 좁힐 수 있습니다.

## 신청 전 정리 순서

1. 관심 있는 복지서비스 이름을 찾습니다.
2. 서비스URL로 이동해 지원대상과 선정기준을 확인합니다.
3. 소득, 재산, 가구원, 거주지역 조건을 따로 메모합니다.
4. 복지체크 계산기로 월소득, 주거비, 대출이자, 공과금 같은 숫자를 정리합니다.
5. 최종 신청 전에는 복지로 또는 담당 기관 문의처에서 최신 접수 가능 여부를 확인합니다.

## 중앙부처 사업과 지자체 사업을 먼저 나누세요

공공데이터포털의 복지서비스 정보는 중앙부처 사업이 중심입니다. 그래서 “우리 동네에서 하는 지원금”이 검색되지 않는 경우가 생깁니다. 두 가지는 확인 경로가 다릅니다.

| 구분 | 확인 경로 | 주의할 점 |
|---|---|---|
| 중앙부처 사업 | 공공데이터포털 복지서비스 정보, 복지로 | 전국 공통 기준이지만 지자체별 추가 조건이 붙을 수 있습니다. |
| 지자체 사업 | 시·군·구 홈페이지 공고, 주민센터 | 예산 소진으로 조기 마감되는 경우가 많습니다. |

같은 이름의 사업이라도 시행 주체가 다르면 소득 기준과 접수기간이 다를 수 있으므로, 공고문에 적힌 시행 기관을 먼저 확인하는 것이 안전합니다.

## 흔한 실수

검색 결과의 요약만 보고 대상이라고 판단하는 경우가 많습니다. 서비스요약은 말 그대로 요약이라 소득 기준, 연령, 가구 조건 같은 핵심 요건이 빠져 있을 수 있으므로 반드시 서비스URL의 상세 안내까지 열어봐야 합니다.

최종수정일이 오래된 자료를 그대로 쓰는 것도 위험합니다. 최종수정일이 지난해에 멈춰 있다면 올해 기준이 반영되지 않았을 수 있으므로 복지로나 담당 기관 공지로 한 번 더 확인하세요.
