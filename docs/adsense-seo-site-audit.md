# 소소타임 애드센스/SEO 구조 점검

최종 점검일: 2026-07-04

## 사이트 성격

소소타임은 생활 유머, 공감 사연, 커뮤니티 이슈를 원문 복제 없이 자체 요약과 해설로 정리하는 큐레이션형 콘텐츠 사이트입니다.

핵심 방향:

- 원문 전체 복제 금지
- 자체 문장으로 상황, 반응, 확인할 점 정리
- 출처 링크 제공
- 게시글별 독립 상세 페이지 제공
- 이미지와 본문을 갖춘 정적 콘텐츠 구조

## 요청 조건별 점검

### 1. 애드센스 승인 목적

현재 구조는 승인 준비 방향에 맞습니다.

반영된 항목:

- 메인 페이지, 상세 페이지, 정책 페이지 존재
- 개인정보처리방침, 이용약관, 운영 안내, 문의, 신고/삭제 요청 페이지 존재
- 애드센스 스크립트가 주요 페이지와 게시글 `<head>`에 포함됨
- 원문 복제 대신 자체 요약/해설 구조 사용
- sitemap, robots.txt 제공

보강할 점:

- 승인 전에는 글 수를 꾸준히 늘려 최소 30~50개 이상의 독립 콘텐츠를 확보하는 것이 좋습니다.
- 각 글은 너무 짧지 않게 4개 이상 섹션과 충분한 문단을 유지합니다.
- 외부 원문 이미지 무단 사용은 피하고 자체 제작 또는 권한 확인 이미지 위주로 운영합니다.

### 2. 애드센스 승인 후 수익 목적

기본 수익형 구조는 준비되어 있습니다.

현재 장점:

- 홈에서 인기글, 최신글, 카테고리별 글로 회전 유입 가능
- 상세 페이지마다 관련글 영역이 있어 내부 이동 가능
- 유머/공감/생활/정보/이슈 카테고리로 확장 가능

추가 보강 방향:

- 승인 후 본문 중간, 본문 하단, 사이드 영역에 광고 슬롯을 단계적으로 추가합니다.
- 승인 전에는 과도한 광고 자리 표시를 줄이고 콘텐츠 신뢰도를 우선합니다.

### 3. 네이버, 구글 SEO 구조

현재 구조는 검색 노출 기본 요건에 맞습니다.

반영된 항목:

- 글마다 고유 URL
- canonical URL
- meta description
- Open Graph/Twitter meta
- Article JSON-LD
- BreadcrumbList JSON-LD
- sitemap.xml
- robots.txt
- 내부 링크: 메인, 관련글, 카테고리 필터

보강할 점:

- 카테고리별 독립 정적 페이지를 만들면 SEO가 더 좋아집니다. 현재는 `/?category=funny` 같은 필터 중심입니다.
- 인기글/최신글 목록은 좋지만, 장기적으로 `/category/funny/`, `/category/empathy/` 같은 정적 목록 페이지를 추가하는 것이 좋습니다.

### 4. 별도 어드민 페이지 불필요

조건에 맞습니다.

- 관리자 페이지 없음
- 로그인/회원가입 UI 제거
- 제보 페이지는 운영자에게 이메일로 제보하는 안내 페이지로 유지

### 5. 컨셉 참고 + 애드센스 승인 콘텐츠 구조

현재 홈은 유머 커뮤니티 느낌을 참고하되 그대로 복제하지 않고 재배치했습니다.

반영된 구조:

- 큰 히어로 이미지
- 오늘의 인기글
- 카테고리별 인기글
- 최신 글
- 실시간 인기
- 에디터 추천
- 오늘의 짤
- 인기 태그
- 운영 규칙 안내

애드센스 승인 관점의 보강:

- 단순 링크 모음이 아니라 상세 페이지마다 자체 본문을 제공
- 신고/삭제 요청, 운영 안내, 개인정보 페이지 제공
- 원문으로 이동하는 출처 링크 제공

### 6. GitHub 연동

현재 GitHub 원격 저장소가 연결되어 있습니다.

```text
origin https://github.com/ana7776/sosotime.git
branch main
```

추가 보강:

- `.github/workflows/ci.yml`: 빌드 검증
- `.github/workflows/deploy-cloudflare-pages.yml`: main 브랜치 푸시 시 Cloudflare Pages 배포

GitHub Secrets 필요:

```text
CLOUDFLARE_API_TOKEN
CLOUDFLARE_ACCOUNT_ID
```

### 7. 이미지 R2/WebP 자동화

기본 자동화 틀은 준비되어 있고 보강했습니다.

현재 지원:

- 외부 이미지 URL 다운로드
- 로컬 이미지 파일 입력
- Sharp WebP 변환
- 1200x675 리사이즈
- Cloudflare R2 업로드
- 공개 URL JSON 반환
- dry-run 검증

주의:

- 이미지 크롤링은 권한 확인이 된 이미지에만 사용합니다.
- 승인 전에는 직접 생성한 WebP 이미지 또는 권한이 명확한 이미지를 우선합니다.

## 현재 결론

소소타임은 “애드센스 승인 전 점검용 사이트”로 필요한 큰 구조는 갖춘 상태입니다.

완료된 핵심:

- Cloudflare Pages 배포
- GitHub 원격 연결
- GitHub Actions 배포 워크플로 추가
- 애드센스 head 스크립트 삽입
- sitemap/robots 제공
- 개인정보/약관/운영/문의/신고 페이지 제공
- 로그인/회원가입 제거
- 오늘자 콘텐츠 추가
- R2 이미지 자동화 문서 및 코드 보강

다음 보강 우선순위:

1. 글 수를 30~50개 이상으로 확장
2. 카테고리 정적 페이지 추가
3. 승인 전까지 외부 이미지 무단 사용 방지
4. Search Console, Naver Search Advisor에 sitemap 제출
